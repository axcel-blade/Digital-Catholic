# Support

## Getting help

### Questions about contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md) first — it covers the branch model, how to add content, code style expectations, and the release process.

### Questions about content

Read [src/data/README.md](src/data/README.md) for how content files are structured and how to add a new article to any section.

### Something looks wrong on the site

If you notice incorrect information, a broken page, or a content error:

1. Check whether the issue already exists in [GitHub Issues](https://github.com/axcel-blade/Digital-Catholic/issues).
2. If not, open a new issue with the **Bug** template — include the URL of the affected page and a description of what is wrong.

### Feature or content requests

Open an issue using the **Content Request** template to suggest a new section, article, or feature.
